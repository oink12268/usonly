UsOnly 계정 삭제 안내

UsOnly는 커플이 함께 쓰는 개인용 앱으로, 계정과 데이터를 삭제하는 방법은 다음과 같습니다.

앱에서 직접 삭제하기

  1. UsOnly 앱 실행 후 로그인
  2. 프로필 화면으로 이동
  3. 화면 하단의 "회원탈퇴" 선택
  4. 안내를 확인하고 탈퇴 진행
삭제되는 데이터
  • 내 계정 정보 (이메일, 닉네임, 프로필 사진, 로그인 정보)
  • 커플로 연결되어 있던 경우, 함께 만든 채팅·앨범(사진/영상)·메모·일정·기념일·쿠폰 기록 전체

탈퇴 시 커플로 연결된 상대방의 계정 자체는 삭제되지 않으며, 커플 연결만 해제됩니다. 단, 위에 나열된 함께 쌓은 기록은 상대방 화면에서도 함께 사라집니다.

탈퇴 즉시 처리되며 되돌릴 수 없습니다.
